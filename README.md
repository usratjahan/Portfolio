# Assignment 1 – Portfolio

A responsive personal portfolio website built from the assets supplied in the assignment ZIP.

## Files
- `index.html` – page structure
- `style.css` – full responsive styling
- `script.js` – mobile menu, reveal animations and dynamic footer year
- `assets/` – supplied logo, portrait, galaxy GIF and project screenshots

## Run
Open `index.html` directly in a browser, or run it with VS Code Live Server.

## Note
The supplied `portfolio.fig` file is binary-corrupted in the uploaded archive (its internal ZIP metadata cannot be cleanly extracted), so this implementation uses all recoverable supplied assets and reconstructs a complete responsive portfolio layout around them.
